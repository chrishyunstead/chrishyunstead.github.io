ABOUT ME 👨‍💻

졸업 후 실무 역량 강화를 위해 플레이데이터 엔코아 아카데미의 데이터 애널리시스 과정을 수료했습니다. 부트캠프에서는 데이터 수집, 전처리, SQL, ML 모델 학습, AWS 기반 DB 모델링, Django 프레임워크를 활용한 웹 서버 배포 등 데이터 전 주기 기술을 다루며 실무 능력을 쌓았습니다.

현재는 딜리버스(Delivus)에서 MLOps 엔지니어로 근무하며, 배송 추적 데이터 분석 및 클러스터링·예측 모델의 개발과 유지보수를 담당하고 있습니다. 당일배송 회사로서 SLA(Service Level Agreement)를 준수하기 위해 허브 출차 효율을 높이는 것이 핵심 과제이며, 이를 위해 우편번호 기반 그룹화 클러스터링 기술을 개발하여 라우트 편집 시간을 단축했습니다. 또한, 지역 간 경계 문제를 최소화하고 운영 효율을 높이기 위해 오버랩(Overlap) 클러스터링 알고리즘을 개발하였으며, 지역별 최대 배송량 예측 모델을 운영 파이프라인에 통합하여 실시간 클러스터링 프로세스가 자동으로 작동하도록 개선했습니다. 이와 함께 GIS 기반 프로젝트의 운영 안정화에도 기여하며, 데이터 기반 물류 의사결정의 신뢰성과 속도를 강화하고 있습니다.

이처럼 학문적 기반과 실무 경험을 결합하여 문제 해결 중심의 사고와 기술적 실행력을 키워왔으며, MLOps 엔지니어로서 지속적인 성장과 혁신을 이어가고 있습니다.
