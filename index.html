실도로·실시간 교통 기반 경로최적화: OSRM + ITS + ALNS Route Optimization

서비스 기능

  • OSRM 기반 실도로 거리·시간 매트릭스 생성 및 운영 요청 단위 경로 산출
  • ALNS 기반 최적 방문 순서(TSP) 탐색으로 라이더 주행 효율 개선
  • 캐싱/정수화(Quantization) 적용으로 실행 시간 단축 및 결과 안정화(재현성 확보)
  • AWS Lambda 및 ECS 환경에 배포가능한 운영 형태로 구성하여 운영 시스템/라이더 앱에서 호출 가능한 형태로 제공

핵심 구현 프로세스

  • 1) 교통 데이터 스냅샷
    ITS 속도 데이터를 5분 단위로 수집하여 Grid 속도 스냅샷 생성
  • 2) OSRM 반영
    스냅샷을 segment-speed CSV로 변환 후 OSRM customize/datastore 반영(변경 감지 포함)
  • 3) Matrix 생성
    OSRM table API로 거리/시간 매트릭스(dist/dur matrix) 생성
  • 4) ALNS 최적화
    Adaptive Large Neighborhood Search로 방문 순서 최적화 (TSP/준VRP 형태 확장 가능)
  • 5) 재현성/성능 최적화
    matrix quantize(정수화) + 문제키(hash) 캐시 + 결정적 seed로 결과 안정화 및 속도 개선
  • 6) 운영 연동
    경로 산출 결과를 API 응답 형태로 표준화하여 운영 시스템/라이더 앱에서 즉시 사용 가능하도록 구성

서비스 효과

  • 실서비스 배포 가능한 형태로 제공
    SAM 기반 패키징/로컬 테스트로 배포 품질을 확보하고, DevOps 배포 파이프라인에 연동되어 실서비스 호출 흐름에 통합되었습니다.
  • 속도 및 안정성 강화
    캐싱/정수화로 계산 비용을 줄이고 결과 흔들림을 최소화하여 운영 신뢰성 확보
  • 라우팅 품질 개선
    휴리스틱 대비 더 나은 방문 순서를 탐색하여 라이더 주행 효율 및 운영 의사결정 지원
