# Bilingual GitHub Pages Deployment

This folder is ready to replace the contents of the existing `chrishyunstead.github.io` repository.

## URL structure

- English portfolio: `https://chrishyunstead.github.io/`
- Korean portfolio: `https://chrishyunstead.github.io/ko/`

## Structure

```text
chrishyunstead.github.io/
├── index.html          # English main portfolio
├── ko/
│   └── index.html      # Korean portfolio
├── styles.css
├── favicon.ico
└── image assets
```

The original Korean page was moved into `ko/index.html`, and local image/CSS paths were adjusted accordingly.
